# Memory Match 🧠

Memory Match is an interactive card-matching game built with React and JavaScript. Flip cards, find matching pairs, and challenge your memory through an engaging interface.

## Features

- **Interactive Card Flipping:** Reveal cards by selecting them.
- **Matching Logic:** Find matching pairs to progress through the game.
- **Difficulty Settings:** Choose from the difficulty options implemented in the application.
- **Game State Management:** Manage card selections and matching states with React.
- **Responsive Interface:** Play across different screen sizes.
- **Card Animations:** Visual feedback when interacting with cards.

## Tech Stack

- React 19
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite 6

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/anienam/memory-match-react.git
```

Navigate into the project:

```bash
cd memory-match-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Build the application:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## How to Play

1. Start a game.
2. Select a card to reveal its symbol.
3. Select another card to find a matching pair.
4. Continue matching cards until you complete the game.
5. Try different difficulty settings to challenge yourself.
